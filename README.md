# GNDO Data Factory

GNDO Data Factory is an open research project focused on building the foundational data infrastructure for a Global Nuclear Development Operating System (GNDO).

The platform automates the collection, organization, and analysis of nuclear regulatory, licensing, reactor design, and deployment data across multiple reactor ecosystems, including AP1000, APR1400, and future advanced reactor technologies.

The long-term vision is to accelerate nuclear deployment through AI-powered regulatory intelligence, crosswalk analysis, and knowledge graph technologies.
